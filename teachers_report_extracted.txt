1. Summary
The Kalimati Market Analytics System is a full-stack, cloud-deployed decision-support platform
designed to track, analyze, and forecast agricultural commodity prices from NepalΓÇÖs Kalimati
Market. By integrating automated data engineering, optimized relational databases, complex
backend analytics, machine learning, and an interactive React frontend, the system provides
stakeholders with real-time risk assessment, historical trend analysis, and predictive pricing
intelligence.
2. System Architecture & Cloud Deployment
The system is built on a highly decoupled, modern five-layer modular architecture, deployed
entirely on scalable cloud infrastructure.
Cloud Deployment (Orchestrated by Subrna Thakurathi)
The application leverages a distributed, serverless architecture to ensure high availability and
performance:
ΓÇó Frontend (Vercel): The React-based user interface is deployed on Vercel, which provides a
globally distributed Edge Network for sub-second page loads. Vercel automatically builds
the application via Vite.
ΓÇó Backend API (Render): The FastAPI Python backend is deployed as a web service on
Render. It is connected directly to the GitHub repository, facilitating Continuous Integration
and Continuous Deployment (CI/CD) pipelines for automatic redeployments upon code
pushes.
ΓÇó Database (Neon Serverless Postgres): The PostgreSQL database is hosted on Neon. This
serverless database architecture separates compute from storage, allowing it to scale
resources on-the-fly to handle heavy analytical query loads while maintaining strict security.
3. How the System Works (Core Functionalities)
A. Data Engineering & ETL Pipeline
The system automates the ingestion of over 102,000 raw market records. Missing data (such as
weekends or market holidays) is handled using a tiered imputation algorithm: forward-fill is
applied for gaps of 1-3 days, and linear interpolation is used for gaps of 4-14 days. The pipeline
normalizes the data and performs incremental database updates, reducing daily sync times from 8
minutes to 2 minutes.B. High-Performance Analytics
The system ranks 147 unique commodities by market volatility (standard deviation), detects sudden
price spikes using rolling-window averages, and calculates market spreads. To handle these heavy
mathematical operations without lagging the UI, the backend uses PostgreSQL JSONB caching to
store and retrieve pre-computed metrics in milliseconds.
C. Machine Learning Forecasting
The predictive engine utilizes a statistical ARIMA (2, d, 1) model to forecast prices 30 days into
the future. It dynamically runs an Augmented Dickey-Fuller (ADF) test to ensure the mathematical
stationarity of the pricing data before fitting the model. Predictions are returned alongside a 95%
confidence interval band and are continuously monitored using MAE, RMSE, and MAPE error
metrics.
D. Interactive UI
The frontend visualizes the data through interactive Recharts, including line charts, seasonal area
charts, and risk-comparison bars, all housed within a responsive Single-Page Application (SPA).
